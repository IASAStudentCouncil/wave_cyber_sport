# WAVE Cyber League
This repository contains the landing page for the **WAVE Cyber League**, an event organized by IASA to promote esports among students. The page provides essential details about the tournament, including important dates, match schedules, live streams, and more.

## About
The **WAVE Cyber League** landing page was designed to promote and facilitate the event, providing participants and viewers with all the necessary information. The design captures the vibrant and competitive spirit of esports, making it engaging for the student community.

- **Design:** [View the design on Figma](https://www.figma.com/file/BjhghbSaEMCzcdMcsUudh3/WAVE-site)
- **Live Demo:** [Explore the landing page](https://iasastudentcouncil.github.io/wave_cyber_sport) (unavailable since 2020)

## Development
To contribute to or modify the landing page, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/IASAStudentCouncil/wave_cyber_sport.git
   ```

2. Navigate to the project folder:
   ```bash
   cd wave_cyber_sport
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server and watch for changes:
   ```bash
   npm run dev
   ```
   - The development server will automatically reload when you edit files.
     
5. After finishing work create pull request in master branch. Ask somebody to accept your PR :)
     
Note: _Always pull the latest changes before starting your work to avoid conflicts._
     
## Production
To prepare the site for deployment:

1. Pull the latest changes from the master branch:
   ```bash
   git pull origin master
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Compile and minimize assets:
   ```bash
   npm run dev
   ```
